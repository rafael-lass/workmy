## Objetivo

Editar o catálogo do profissional com conteúdo estruturado, capa e classificação reutilizável.

## Escopo técnico

- [x] CRUD por usuário com nome único entre serviços não excluídos.
- [x] Editor Tiptap com documento JSON versionado, validação no backend e limite de 20 mil caracteres.
- [x] Upload de PNG/JPEG/WebP até 5 MiB; tags limitadas a dez por serviço.
- [x] Catálogo privado de tags com normalização de espaços e caixa, e associação N:N em servico_tags.
- [x] Preservar conteúdo do formulário ao falhar uma operação remota.

## Critérios de aceite

- Descrição e formatação salvas reaparecem ao editar; nós ou links não suportados são rejeitados.
- Tags não se duplicam por caixa/espaços e não são compartilhadas entre usuários.
- Remover seleção de tag não apaga a tag do catálogo.

**Tipo:** Domínio, API SQLite e componentes  
**Status:** Aprovado

- Usuários service_owner/service_other criados pelo teste; formulário de serviços usa API simulada.

**Passos**

1. Criar '  Web   Design  ' e 'web design' na API e comparar o resultado.
